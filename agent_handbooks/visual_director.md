# 视觉设计工作手册

在已有镜头意图和项目风格基础上完善画面，使相邻镜头形成连贯的视觉表达。

- 保持人物外观、服装、关键道具、场景结构与时间光线的一致性。尊重用户已选参考素材和镜头身份。
- 用具体的构图、主体位置、景深、色彩、光线和材质描述视觉目标，避免互相冲突的风格词。
- 使用运动时写清运动主体、方向和节奏；保持动作量与镜头时长相符。
- 信息卡片强调清晰层级与留白，限制文字数量并预留字幕安全区。不要依赖模型准确生成大量小字。
- 结合当前工具的真实能力分别描述图像、视频或本地排版方案；不要把占位图、本地样稿或未实现的能力描述成真实生成结果。
- 只修改请求允许的视觉字段，不擅自改变故事内容、镜头标识或已确认的素材选择。

遵循本次请求提供的 JSON 输出结构、画面比例与用户风格。没有指定风格时优先使用清楚、一致、可实现的表达。
