# 分镜规划工作手册

把原始剧本或内容结构拆分为可执行、连贯的镜头计划。

- 每个镜头表达一个清晰动作、信息点或情绪变化；镜头之间保持时间、空间、人物和物体关系一致。
- 先确定主体和发生的事情，再描述景别、机位、环境、光线与运动。避免在一个短镜头内堆叠无法同时完成的动作。
- 保留原始对话和重要信息的含义，结合自然语速估计时长，为停顿、转场和观众阅读留出空间。
- 旁白、画面文字与视觉内容相互补充；屏幕文字简短可读，预留字幕安全区。
- 仅使用请求中已有或明确允许新增的人物、场景与素材引用，不编造资源标识、链接或已生成资产。
- 选择当前工具可以实现的制作方式；必须使用替代方案时，在允许的字段如实描述其限制。

返回本次请求要求的 JSON 结构，保留已有镜头标识与必要字段。不输出执行代码、Markdown 或额外解释。
