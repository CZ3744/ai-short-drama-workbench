# 工作台体验升级任务

目标：在现有 Claude 原始设计上，延续暖纸白、柔和灰阶、陶土色，并吸收 iOS 的圆角层次与操作反馈，让视频工作台易用、好用、美观、合理。

## 完整工作范围

1. 新用户：明确项目用途、配置入口、自己的 API、免费与付费渠道的区别。
2. 工作台：项目检索与排序、继续创作、真实状态、清楚的空白和失败状态。
3. 创作：灵感、剧本、分镜、人物与场景、单镜首帧和视频、合成导出全旅程。
4. 交互：可靠保存、重复操作、切页状态、快捷键、焦点、触控与窄屏可达性。
5. 视觉：保留已有设计语言，统一文字层次、间距、圆角、按钮反馈，尊重减少动态效果偏好。
6. 可靠性：并发、断线重连、错误恢复、本地服务访问边界、数据保留。
7. 分发：无个人信息、无用户作品、无凭据；每位用户自行配置服务；保留扩展能力。
8. 交付：隔离测试、逐页真实浏览器截图与视觉复核、构建与安装验证、GitHub 私有项目主页。

## 完成标准

- 构建、针对性与完整测试通过；新增修复有真实行为验证。
- 所有正式路由类型及关键设置/状态标签实际打开并截图，桌面与窄屏布局复核。
- 以离线样本验证本地工作流，不把样本或模拟结果描述为云端付费生成验收。
- 发布副本通过隐私扫描；没有旧个人配置、工作日志、真实素材或旧 Git 历史。
- GitHub 返回私有可见性，远端提交与交付副本一致。

## 工作方式

首页/外壳、创作流程、后端可靠性并行实施；整合后集中验证、视觉检查、修复、重拍。
原项目与运行数据保留。发布副本从明确允许的源码和通用文档导出，不重写原仓库历史。
