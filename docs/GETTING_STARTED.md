# 开始制作第一部短剧

## 安装并启动

1. 安装 Node.js 24，在项目目录运行 `npm ci`。
2. Windows 双击 `start-studio-hidden.vbs`。后台服务静默启动，准备好后打开浏览器。
3. 浏览器地址为 `http://127.0.0.1:5173`。其他平台可使用 `npm run dev`；当前重点验收环境为 Windows。

## 连接你自己的模型

打开「设置 → 文字模型 → 新增模型」。填写名称、服务地址、模型 ID 与 API Key，选择服务商实际提供的协议。OpenAI 兼容服务通常使用自己的 `/v1` 地址；Anthropic 接口请选择对应协议。保存后测试连接。

按需要配置图像、视频和语音模型。已填写凭据、启用服务、测试成功是不同状态；界面会区分它们。不要把他人的 `local-settings.json` 复制到自己的安装。

生成按钮旁可以选择本次使用的模型；无需为了某个镜头反复更改全局配置。具体可用模型、计费与授权由服务商决定。

## 一步步制作

1. 新建系列，填写标题与简介，选择画面比例。创建后从卡片进入作品。
2. 在灵感收件箱收集想法，或在剧本页自己写、粘贴已有文本。观察保存状态；失败时保留文本并点击重试。
3. 拆分镜后检查镜头描述、人物与场景关联；所有提示词可先查看和修改。
4. 在素材页建立人物、场景和需要复用的元素，选择参考图以保持一致性。
5. 逐镜制作首帧与视频，或导入现有图片/视频；确认采用哪一个候选。
6. 合成页检查镜头准备情况，配置配音、字幕和画面规格，预览后导出。

本地卡片图是样稿工具。它便于学习流程，不替代云端模型或正式作品素材。

## 合成前准备

FFmpeg 和 FFprobe 用于视频检测、字幕和合成。请将两者加入 PATH 并确认 `ffmpeg -version` 与 `ffprobe -version` 可运行。个别模块支持路径配置，但完整合成目前仍依赖 PATH。Edge TTS 需要可访问网络及对应 Python 包；没有语音服务时可使用已有音频或按页面提供的无配音流程处理。

可选本地模型的 Python、推理脚本和模型文件不包含在代码仓库中。根据自己的安装填写公开 preset 的 executor 配置；未配置的扩展默认关闭。

## 作品与备份

作品位于项目自己的 `data/`，导出在 `outputs/`。使用设置页的数据管理功能备份；迁移时保留数据、配置与数据库配套文件。删除操作优先进入回收站。不要把运行中的 SQLite 主库和旧 WAL 文件随意拼接。

## 遇到问题

- 页面连接失败：确认静默启动完成，前端和后端端口未被其他程序占用。
- 模型不可用：在设置中检查服务地址、模型 ID、自己的 API Key 和测试状态。
- 保存未完成：保留页面中的文本，重试成功后再切版本或开始生成。
- 生成失败：查看任务面板和系统状态，确认服务商额度及请求信息，再决定是否重试。
- 不能导出：先检查镜头素材与合成结果，确认本机 FFmpeg 可用。

停止工作台使用 `stop-studio.vbs`，它只处理本项目启动的服务。
