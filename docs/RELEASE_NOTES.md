# 0.2.2 · AI 短剧生成工作台，公开测试

项目统一使用「AI 短剧生成工作台 / AI Short Drama Workbench」，仓库更名为 `ai-short-drama-workbench`。适合制作 AI 短剧、AI 漫剧与剧情短片：写剧本、排分镜、整理参考图和镜头素材，再合成视频。

本次更新中英文首页、应用名称、安装指令和文档索引，保留真实界面截图与样例。沿用 MIT 许可，使用者自行配置模型服务和 API Key。

这是源码和本地工具的公开测试版，推荐 Windows + Node.js 24。编辑、素材管理与本地合成延续 0.2.1 的验收范围；模型输出质量、费用与服务可用性取决于所接服务。浏览器设置键、备份目录和运行时身份保持兼容，已有作品无需迁移。

# 0.2.1 · 从编辑到导出，走完一遍

这次先修实际操作中会卡住的地方，再整理项目首页。核心流程用虚构故事和本地素材实跑，没有调用作者的账户或付费模型。

## 创作流程修复

- 已保存的新剧本会用于后续素材提取与分镜规划，旧 `script.md` 不再覆盖当前编辑。
- 连续回车输入时保留光标与空段；文首、文末和 Shift 扩选同步更新编辑器选区。
- 合成画幅兼容预设与已存值，正确读取系列默认画幅，刷新后保留选择。
- 粗剪尊重字幕开关和自定义样式，短配音不会提前截断较长的镜头。
- 缺失可选 Python 工具时返回明确的降级信息，不再因未处理的进程错误退出。
- Windows 短暂文件占用采用有限重试和独立临时文件；持续失败保留旧文件并报告错误。
- 成片历史排除内部中间视频；没有最终成片时不再拿源片冒充下载结果。
- ZIP 操作明确写为“导出”，与实际保存到本机的行为一致。

## 更容易开始

首页补上真实样例与两张宣传图；新增英文说明、常见问题、可复制的 AI 本地安装指令和 `npm run doctor`。文档说明了模型费用、数据去向和实际支持范围。

## 本轮验证

763 项自动测试通过，0 失败、0 跳过；99 项真实浏览器检查通过。另用自然命名样例完成 7 项连续操作：创建、设参考图、导入与选素材、审核提示词、选择画幅并合成播放、导出 ZIP、快速输入并保存刷新。两组浏览器检查均无页面异常和外部请求。

媒体集成测试实际调用 FFmpeg，检查字幕像素、音轨、片长、下载文件解码和缺失素材状态。测试用的 LLM / TTS 接口为明确的本地 fixture，不能据此声称所有商业模型服务已经实测。

# 0.2.0 · 创作体验与可靠性升级

## 更顺手的工作台

延续 Claude 暖纸白、灰阶与陶土色，保留衬线标题，统一 iOS 风格的圆角与反馈。首页加入检索、排序、继续创作、清晰的空状态、加载骨架和错误重试。新建作品后由创作者决定何时进入。

## 编辑与生成

- 剧本串行保存；保存时继续输入不会误报成功。失败可重试，标签页内草稿可恢复。
- 切换版本、接受较早的 AI 建议前保存快照；不同分集和镜头状态隔离。
- 封面预览与生成共用提示词编译器，包含当前作品上下文与参考图；修改内容真正发送。
- 合成进度使用实际素材与确认状态；修复字幕自定义参数和成片缓存地址。
- 设置页支持分类链接、自己的 API 与模型、明确区分已配置和已测试。

## 运行与分发

增加本机请求访问边界；慢速 SSE 客户端限制积压并重新同步；静默启动验证应用身份。可选本地模型不再依赖作者的音色目录。源码发布为不带个人历史、配置、凭据和作品的通用副本，采用 MIT 许可。

升级编辑器、图像处理和上传等依赖，删除带有已知高风险传递依赖的通用命令启动器，改为固定参数的本项目启动脚本。

## 验证记录

744 项测试、98 项浏览器检查通过；122 张实际截图经逐图复核。干净安装、静默启动/停止、代码健康和发布隐私扫描通过。完整结果见 [逐页视觉与交互验收](VISUAL_REVIEW.md)。验证使用隔离人工样本；真实云端付费生成未作为本次离线验收范围。

## 依赖记录

依赖审计剩余 `mammoth → argparse → sprintf-js` 的三项中风险传递告警；npm 建议的自动方案会把文档解析库降至旧的不兼容版本，因此未强制降级。本项目使用 Mammoth 的文档转换接口，不运行其命令行参数解析器。完整合成需要 FFmpeg / FFprobe 在 PATH 中。

参考：[Tiptap 公告](https://github.com/advisories/GHSA-cp6q-959q-f8rh)、[sprintf-js 公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。
