# 0.2.0 · 创作体验与可靠性升级

## 更顺手的工作台

延续 Claude 暖纸白、灰阶与陶土色，保留衬线标题，统一 iOS 风格的圆角与反馈。首页加入检索、排序、继续创作、清晰的空状态、加载骨架和错误重试。新建作品后由创作者决定何时进入。

## 编辑与生成

- 剧本串行保存；保存时继续输入不会误报成功。失败可重试，标签页内草稿可恢复。
- 切换版本、接受较早的 AI 建议前保存快照；不同分集和镜头状态隔离。
- 封面预览与生成共用提示词编译器，包含当前作品上下文与参考图；修改内容真正发送。
- 合成进度使用实际素材与确认状态；修复字幕自定义参数和成片缓存地址。
- 设置页支持分类链接、自己的 API 与模型、明确区分已配置和已测试。

## 运行与分发

增加本机请求访问边界；慢速 SSE 客户端限制积压并重新同步；静默启动验证应用身份。可选本地模型不再依赖作者的音色目录。源码发布为不带个人历史、配置、凭据和作品的通用副本，采用 MIT 许可。

升级编辑器、图像处理和上传等依赖，删除带有已知高风险传递依赖的通用命令启动器，改为固定参数的本项目启动脚本。

## 验证记录

744 项测试、98 项浏览器检查通过；122 张实际截图经逐图复核。干净安装、静默启动/停止、代码健康和发布隐私扫描通过。完整结果见 [逐页视觉与交互验收](VISUAL_REVIEW.md)。验证使用隔离人工样本；真实云端付费生成未作为本次离线验收范围。

## 依赖记录

依赖审计剩余 `mammoth → argparse → sprintf-js` 的三项中风险传递告警；npm 建议的自动方案会把文档解析库降至旧的不兼容版本，因此未强制降级。本项目使用 Mammoth 的文档转换接口，不运行其命令行参数解析器。完整合成需要 FFmpeg / FFprobe 在 PATH 中。

参考：[Tiptap 公告](https://github.com/advisories/GHSA-cp6q-959q-f8rh)、[sprintf-js 公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。
