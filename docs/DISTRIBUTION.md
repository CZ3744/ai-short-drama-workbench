# 分发与隐私

发布项目是通用应用：每位用户在自己的电脑运行，连接自己的模型服务。MIT 许可允许使用、修改和分发；仓库私有可见性与软件许可是两个独立设置。

## 发布材料

包含应用源码、公开默认 preset、空配置示例、提示词模板、隔离测试、通用文档与人工样本截图。可选本地扩展保留代码，但清空机器相关 executor 路径并默认停用，等待使用者自行配置。

不包含作者的 `.env`、模型密钥、OAuth 会话、运行配置、数据库、作品、导出文件、日志、助手交接文件、历史审计档案和原始 Git 历史。

`scripts/export-release.mjs` 按明确允许的目录导出新副本，生成 SHA-256 文件清单，并处理机器路径。它不会删除或覆盖原始项目与数据。发布副本建立独立的干净 Git 历史，避免已删除的信息通过旧 commit 被重新读到。

## 用户配置

推荐在设置页添加模型。凭据写入本机 `config/local-settings.json`，由 `.gitignore` 排除；可选 `.env` 同样不提交。配置页会隐藏密钥，错误返回会脱敏。凭据仅作本机可逆混淆保存，不属于安全加密，应使用操作系统账户与磁盘权限保护，不能把电脑共享等同于多用户隔离。

页面使用本地字体，不为加载字体请求外部 CDN。应用默认只监听回环地址，并检查本地 Host、Origin 与跨站请求；这不构成公网多用户认证系统。

## 验收范围

自动测试使用单独的临时副本、临时数据库和人工样本。网络护栏防止误调用真实服务，但不是操作系统安全沙箱。浏览器验收证明界面与本地 API 的交互；它不证明每一家付费服务的生产额度、质量和可用性。

运行 `npm run check:privacy` 扫描已跟踪的发布文件。模式扫描是最后一道辅助检查，不能取代明确排除用户数据的导出规则。截图必须来自隔离样本。
