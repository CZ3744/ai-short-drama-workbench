# 使用前，你可能想问

## 这是做什么的？

AI 短剧生成工作台（AI Short Drama Workbench，仓库名 `ai-short-drama-workbench`）是一个采用 MIT 许可的本地创作工具，面向制作 AI 短剧、AI 漫剧和剧情短片的个人创作者。它把剧本编辑、分镜规划、人物与场景参考、镜头素材和视频合成放在同一个工作区，方便逐镜修改。

真人风格与动画风格使用同一套创作流程，最终画面取决于选用的模型与素材。目前处于 0.2.x 公开测试阶段；源码和问题反馈都在 [GitHub 仓库](https://github.com/CZ3744/ai-short-drama-workbench)。

## 能把剧本变成视频吗？

可以按“剧本 → 分镜 → 首帧与视频 → 合成”的流程制作，但需要准备对应的模型服务或已有素材。你仍需要检查分镜、选择候选、调整节奏。它不承诺输入一句话就自动得到可直接发布的成片。

## 工具免费，生成也免费吗？

代码采用 MIT 许可，可以使用、修改和分发。云端模型的收费由所选服务商决定，你使用自己的 API Key。项目不附送模型额度，也不提供共享密钥。

## 没有 API Key，能先试什么？

可以新建系列、写剧本、管理分镜和素材，导入已有图片或视频。有 FFmpeg / FFprobe 时，还能用已有视频片段合成。本地演示卡片方便熟悉流程，但不是 AI 生图结果。

## 必须有显卡吗？

剧本编辑、素材整理和调用云端模型不要求本地独立显卡。可选本地模型有各自的硬件、Python 与模型文件要求；这些模型不随源码附送。合成性能取决于电脑和媒体规格。

## 如何在 Windows 本地安装？能让 AI 代劳吗？

推荐 Node.js 24，下载源码后运行 `npm ci` 和 `npm run doctor`，再双击 `start-studio-hidden.vbs`。合成视频还需要 FFmpeg / FFprobe。[完整安装步骤](GETTING_STARTED.md) 和 [可直接交给 AI 助手的安装指令](AI_SETUP.md) 都在仓库中。

## 可以接任意模型 API 吗？

文字模型支持设置页提供的协议与兼容接口。图像、视频、语音服务以各自现有适配器为准；不能保证把任意服务地址填进去就能调用。先保存配置并测试连接，再尝试一个小任务。

## 我的剧本和密钥会上传到作者那里吗？

项目和设置保存在自己的电脑上，不需要作者提供账号或后端。调用云端模型时，必要的内容与认证信息会发送给你所选的服务商。密钥不会随正常 Git 提交发布，但本地存储的可逆混淆不等于加密，详见 [隐私说明](DISTRIBUTION.md)。

## 可以直接放到公网供多人用吗？

当前面向个人本机使用，默认监听回环地址，尚未提供多用户身份认证、账户隔离与公网托管方案。

## 能保证每个模型、每种文件都成功吗？

不能。仓库提供隔离自动测试、真实浏览器截图和本地媒体合成回归；外部模型的额度、协议变化、内容限制和生成质量仍由各服务决定。遇到问题，欢迎提交去掉密钥和私人内容的最小复现。
