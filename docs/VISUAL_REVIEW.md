## 视觉复核促成的修正

保留 Claude 原始的暖纸白、陶土色与衬线文字，增加清晰的选择反馈、圆角层次和触控间距。真实截图发现并修复了以下问题：

- 侧栏设置和归档入口被长导航挤到视口外。
- 系列统计、分集状态和分镜工具栏在窄屏被压成单字竖排。
- 灵感箱筛选栏占满手机宽度，素材和剧组详情的右栏被裁掉。
- 模型名称、配置标签和筛选按钮互相抢占空间。
- 三个工具弹层受到顶部容器定位影响，标题与关闭按钮跑到视口上方；已挂载到页面根部，并新增几何和遮挡断言。
- 时间线缺少素材时显示大块黑屏；现说明缺失状态并提供制作入口。
- 未加载数据、空数据、计划时长与实际完成状态混淆；去掉无依据的成功暗示与绝对承诺。

保留浅色主题；本轮移除了尚未实现的暗色切换入口。截图中的纯色参考图是隔离测试素材，不代表 AI 图像生成效果。

## 验收边界

构建、全量隔离测试、依赖安装和隐私检查在发布副本中另行执行。真实云端模型的计费、质量、额度、外部网络与服务商可用性，需要每位使用者用自己的 API 验证。完整视频合成依赖本机 FFmpeg / FFprobe，语音服务或本地模型按配置另行安装。

依赖审计没有高风险或严重告警，仍有三项中风险传递告警，见 [发布说明](RELEASE_NOTES.md)。

## 发布副本的独立验证

使用空凭据的脱敏副本执行 `npm ci` 后，744 项测试全部通过（123 个测试组），98 项浏览器检查通过，没有未处理页面错误。生产构建与代码健康检查通过；发布内容隐私扫描无命中。

Windows 静默启动实际拉起前后端，应用身份和首页均确认正确，辅助进程无可见窗口，启动错误日志为空。停止操作后没有遗留本项目服务进程。启动器在 Windows 端口枚举不可用时仍能通过前端身份与精确进程校验完成就绪检查。

全新数据库初始化、字幕真实烧录、Python 子进程行为均有实际测试覆盖。GitHub Actions 使用 Windows、Node.js 24、Python 3.13 和 FFmpeg 复验相同流程，云端结果以仓库 Actions 页为准。
